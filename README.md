simplint is a companion linter for [Ruff](https://github.com/astral-sh/ruff) that enforces the parts of the `simp` house
style Ruff has no rule for, and fixes what it reports wherever the fix is mechanical. See its
[PyPI package](https://pypi.org/project/simplint), [guide](https://simplint.readthedocs.io), and
[release history](CHANGELOG.md). See [CONTRIBUTING.md](CONTRIBUTING.md) for the layout and development commands.
