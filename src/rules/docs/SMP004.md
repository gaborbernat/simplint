## What it does

Checks for a module docstring in a test module. A test module is a file named `test_*.py`, `*_test.py` or `conftest.py`,
or any file under a directory named `tests` or `test` below the project root.

## Why is this bad?

The module path and the test function names already say what is under test. The docstring repeats them and goes stale as
tests move between modules.

## Example

```python
"""Tests for the config loader."""

from app.config import load_config


def test_load_config_empty_file(tmp_path: Path) -> None: ...
```

Use instead:

```python
from app.config import load_config


def test_load_config_empty_file(tmp_path: Path) -> None: ...
```

## Fix safety

The fix deletes the docstring and the blank lines after it, and is safe. No fix is offered when the docstring shares a
line with other code.
