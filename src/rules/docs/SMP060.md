## What it does

Checks for `noqa`, `ruff: noqa`, `type: ignore`, `ty: ignore`, `pyright: ignore`, `pragma: no cover` and
`pragma: no branch` comments that give no reason. A reason is any text after the error codes, or a further `#` comment
on the same line. A `ty: ignore` or `pyright: ignore` without bracketed error codes is reported even when it has a
reason, since it silences every error on the line.

## Why is this bad?

A suppression outlives the problem it hid. Without a reason, a later reader cannot tell whether the error is a false
positive, a known stub gap or a bug someone meant to fix, so nobody dares remove it.

## Example

```python
import os  # noqa: F401

VALUE = os.sep  # type: ignore[attr-defined]
```

Use instead:

```python
import os  # noqa: F401  # re-exported for plugins

VALUE = os.sep  # type: ignore[attr-defined]  # stub omits sep on this platform
```

## Fix safety

No fix is offered: only the author knows why the error was suppressed.
