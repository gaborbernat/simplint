## What it does

Checks for single-letter names everywhere except `for` loop and comprehension targets: functions, classes, parameters
(including lambda parameters), assignment and walrus targets, `with ... as`, `except ... as` and `import ... as` names,
`match` captures and type parameters such as `T`. `_` is allowed. Each name is reported once per scope, at its first
binding.

## Why is this bad?

A single letter says nothing about what the name holds, so the reader has to find where it is bound to learn it. Loop
and comprehension targets are exempt because the iterable they come from sits right next to them.

## Example

```python
def scale(v: float, f: float) -> float:
    r = v * f
    return round(r, 2)
```

Use instead:

```python
def scale(value: float, factor: float) -> float:
    scaled = value * factor
    return round(scaled, 2)
```

## Fix safety

No fix is offered, since a meaningful name cannot be derived from the code.
