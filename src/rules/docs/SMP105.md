## What it does

Checks for `Callable[..., T]`, whether imported from `typing`, `collections.abc` or used through a module attribute. Any
subscript of a name ending in `Callable` whose first argument is `...` matches, including type aliases and other
expressions outside annotations.

## Why is this bad?

`...` accepts any arguments, so the type checker cannot catch a call with the wrong number, type or names of arguments.
A `Protocol` with `__call__` states the parameters, including keyword names and defaults that `Callable[[...], T]`
cannot express.

## Example

```python
def run(callback: Callable[..., None]) -> None:
    callback("build", retries=3)
```

Use instead:

```python
class Callback(Protocol):
    def __call__(self, name: str, *, retries: int) -> None: ...


def run(callback: Callback) -> None:
    callback("build", retries=3)
```

## Fix safety

No fix is offered: the real signature has to be written by hand.
