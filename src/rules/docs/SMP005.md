## What it does

Checks for comment and docstring paragraphs longer than 100 words. In comments, a paragraph is a run of own-line
comments on consecutive lines at the same indentation, ended by an empty `#` line or by any other line; trailing
comments are ignored. In module, function and class docstrings, paragraphs are separated by an empty line. A long
comment paragraph is reported from its first line to the line where it passes the limit, a docstring as a whole.

## Why is this bad?

A paragraph that long usually covers more than one topic, and readers skim it. Split at a change of topic, each part is
easier to find and to keep accurate.

## Example

```python
# Manifests are cached by path and modification time, because parsing them dominates the start-up time of large
# projects. ... The cache is dropped when the interpreter version changes, since the parsed form depends on it.
# (110 words in total)
```

Use instead:

```python
# Manifests are cached by path and modification time, because parsing them dominates the start-up time of large
# projects. ...
#
# The cache is dropped when the interpreter version changes, since the parsed form depends on it. ...
```

## Fix safety

No fix is offered, since where to split a paragraph depends on its meaning.
