## What it does

Checks for modules where the last statement that binds `__all__` (an assignment, annotated assignment or augmented
assignment) is not the last statement. A trailing `if __name__ == "__main__":` block may follow it.

## Why is this bad?

Readers look for the export list in one place. At the end of the module it comes after every definition it names, so it
reads as a summary of what the module provides.

## Example

```python
__all__ = ["main"]


def main() -> None:
    run()


if __name__ == "__main__":
    main()
```

Use instead:

```python
def main() -> None:
    run()


__all__ = ["main"]

if __name__ == "__main__":
    main()
```

## Fix safety

The fix moves the statement to the end of the module, before a trailing `__main__` block, and is safe. It is offered
only when a single statement binds `__all__`, nothing after it reads `__all__`, and it shares no line with other code;
otherwise moving it could change the value of `__all__` or what reads it, so no fix is offered.
