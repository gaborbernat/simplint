## What it does

Checks for `+` chains that join a string or f-string literal with other values. Chains with a bytes literal are not
reported.

## Why is this bad?

A chain of `+` scatters the text across quotes and operators, and every non-string operand needs an explicit `str()`. An
f-string shows the final text in one piece.

## Example

```python
message = "Hello, " + name + "!"
```

Use instead:

```python
message = f"Hello, {name}!"
```

## Fix safety

The fix is always unsafe: `+` raises `TypeError` for a non-string operand and honors a custom `__add__`, while an
f-string formats any value. A chain of literals alone becomes one plain string. No fix is offered when a literal is
implicitly concatenated, triple-quoted, raw or `u`-prefixed, when the literals mix quote styles, or when an operand
spans several lines or contains a backslash, `#`, `:`, `!`, `{` or `}`. Before Python 3.12, an operand that contains the
string's own quote character also blocks the fix.
