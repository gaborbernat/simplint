## What it does

Checks for calls to the builtin `vars`. Calls through a parameter or local named `vars` are not reported, and files that
bind `vars` at module level, for example by defining a function of that name, are skipped.

## Why is this bad?

`vars()` returns a `dict[str, Any]`, so the attribute types are lost and a misspelled key fails only at runtime. Reading
attributes from a typed object keeps both checks in the type checker.

## Example

```python
def options(parser: argparse.ArgumentParser) -> dict[str, str]:
    return vars(parser.parse_args())
```

Use instead:

```python
class Options(argparse.Namespace):
    output: str


def options(parser: argparse.ArgumentParser) -> Options:
    return parser.parse_args(namespace=Options())
```

## Fix safety

No fix is offered: the typed replacement depends on how the result is used.
