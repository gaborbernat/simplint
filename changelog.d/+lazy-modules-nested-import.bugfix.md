[`up-lazy-modules-list`](../src/rules/imports/up_lazy_modules_list.md) keeps `__lazy_modules__` when a listed module is also imported under an `if`, `with`, `for`, `while` or `match`, in the `else` or `finally` of a `try`, or by a relative import of the listed package, where the fix would have left the import eager. An import that is `lazy` already no longer gets a second `lazy`, which produced a syntax error and reverted the fixes of the file.
